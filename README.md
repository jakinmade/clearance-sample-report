# CLEARANCE sample report

A sample AI governance diagnostic of a live AI system, produced by CLEARANCE (clearance-diagnostic.com).
Excel Invests and Jason Butler are fictional. No real organisation or person is assessed.

- [Diagnostic report (PDF)](CLEARANCE-sample-report.pdf): every gap, obligations engaged, remediation roadmap and evidence appendix
- `index.html`: a one-page summary of the same report

CLEARANCE uses fixed, version-controlled rules with no AI model in the decision, so the same inputs always produce the same findings.
