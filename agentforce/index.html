A sealed go-live record for every Agentforce agent you ship

Fixed rules read the agent’s Agent Script file and set out what it can do, who decides when it acts, and what blocks go-live. Your client’s board or risk team gets a record they can verify.

  • Since the week of 13 July 2026, new agents can only be created in the new Agentforce Builder, which is built on Agent Script (Salesforce). Each agent is now one file that can be checked.
  • Salesforce’s own compiler checks that a script is valid. It does not check whether the agent is ready to go live.

How it works

  1. Export the agent fileWith the Salesforce CLI. It holds the agent’s design, not customer data.
  2. Fixed rules read itNo AI in the decision. The same file always gives the same result.
  3. Sealed recordEvery action, who decides when it runs, and what blocks go-live, in your branding.
  4. Re-seal on changeEdit the agent and the seal stops matching, so each release gets a fresh record.
